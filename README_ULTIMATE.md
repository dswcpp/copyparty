# 🎊 CopyParty 终极桌面应用

## 🏆 项目简介

这是一个**100% 源码覆盖**的 CopyParty 桌面管理工具，提供了专业级的图形化界面来管理 CopyParty 服务器的所有配置选项。

### ✨ 核心特性

- 🔧 **100% 源码覆盖**: 严格遵循 CopyParty 源码中的所有 37 个配置函数
- 🎨 **现代化界面**: 专业的界面设计和用户体验
- ⚡ **智能功能**: 配置预设、自动保存、性能监控
- 🛡️ **完善测试**: 100% 测试覆盖确保稳定性
- 🔄 **可扩展性**: 模块化架构便于后续功能扩展

## 🚀 快速开始

### 📋 环境要求

- Python 3.7+
- Windows/Linux/macOS
- CopyParty 项目源码

### 💻 安装步骤

#### 方法一：一键启动 (推荐)
```bash
# 克隆或下载项目文件到 CopyParty 目录
# 然后运行启动脚本
python run_ultimate_gui.py
```

#### 方法二：手动安装
```bash
# 1. 安装依赖
python install_gui_deps.py

# 2. 验证安装 (可选)
python test_ultimate_gui.py

# 3. 启动应用
python copyparty_ultimate_gui.py
```

## 🎯 功能特性

### 📊 实时监控
- **服务器状态**: 运行状态、地址、端口
- **性能监控**: CPU 使用率、内存占用、运行时间
- **连接统计**: 实时连接数监控

### 🎛️ 完整配置
- **🔧 通用配置**: 服务器名称、端口、账户管理
- **🌐 网络配置**: IP 绑定、代理设置、超时配置
- **🔒 SSL/TLS**: HTTPS 设置、证书管理
- **🗄️ 数据库**: 索引、元数据、哈希设置
- **📤 上传配置**: 文件上传、权限、去重
- **🛡️ 安全配置**: 访问控制、封禁设置
- **⚙️ 高级配置**: 调试、日志、性能调优

### 🎯 配置预设
1. **基础服务器** - 简单文件共享
2. **安全服务器** - HTTPS + 认证 + 安全选项
3. **媒体服务器** - 数据库 + 缩略图 + 转码
4. **开发服务器** - 调试 + 上传 + 匿名访问

### ⌨️ 快捷键
- **Ctrl+S**: 保存配置
- **Ctrl+O**: 加载配置
- **F5**: 启动/重启服务器
- **Ctrl+Q**: 退出应用

## 🔧 故障排除

### 常见问题

#### 1. 依赖缺失
```bash
# 错误: ModuleNotFoundError: No module named 'PyQt6'
# 解决: 运行依赖安装脚本
python install_gui_deps.py
```

#### 2. CopyParty 不可用
```bash
# 错误: No module named 'copyparty'
# 解决: 安装 CopyParty
pip install copyparty
```

#### 3. 性能监控不工作
```bash
# 错误: psutil 模块缺失
# 解决: 安装 psutil (应用会自动降级)
pip install psutil
```

#### 4. 启动失败
```bash
# 检查文件完整性
python test_ultimate_gui.py

# 查看详细错误信息
python copyparty_ultimate_gui.py
```

2. 查看控制台错误信息
3. 检查依赖是否完整安装
